Threat Intel extension

Checks every site you visit against your own Threat Intel Aggregator server.

1. Connect to your server

  1. On the computer running the app, start the API: python -m api
  2. It prints the extension token. Admins can also copy it from the app: Settings → Browser extension.
  3. Paste it below and click Save and test.

2. On-page card

High-risk sites always show a red warning bar.

3. Privacy

Only the site's host name (e.g. example.com) is sent to your server, which checks it against VirusTotal, AbuseIPDB, abuse.ch and RDAP using your API keys. Full URLs, page content and form data are never sent. Local and private addresses are never checked.
